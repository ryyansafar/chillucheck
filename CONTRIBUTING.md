# Contributing

1. Write a failing test first (`tests/`), then the fix.
2. Run `python -m pytest -q`; keep coverage at or above 80%.
3. Never remove a ZWJ or ZWNJ (U+200D, U+200C) from data. Fold chillus for matching and sorting only; rewrite data only when its owner asks.
4. Open pull requests on a fork first. Keep changes small and say what you changed and why.
